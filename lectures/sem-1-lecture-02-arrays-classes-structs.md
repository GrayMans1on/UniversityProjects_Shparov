**Программирование: массивы, списки, возврат нескольких значений, структуры и классы**

**1. Массивы**

**Массив** — набор элементов одного типа с фиксированной длиной. Ячейки элементов расположены последовательно → быстрый доступ по индексу.

```csharp
int[] numbers = new int[4];
int value = numbers[0];
int[] answers = new int[numbers.Length];
```

- Размер задаётся при создании, но может вычисляться во время работы программы.
- `Length` — количество элементов; индексы: от `0` до `Length - 1`.
- Элементы нового массива получают значения по умолчанию: `int` → `0`, `bool` → `false`, ссылки → `null`.
- Массив — ссылочный тип: переменная хранит ссылку на объект массива.

**`null`** означает отсутствие ссылки на объект. Обращение к элементам через `null` → `NullReferenceException`.

```csharp
int[] numbers;
```

Эта строка только объявляет переменную. Локальную переменную нужно присвоить перед использованием; автоматически получить `null` здесь нельзя.

Если размер результата неизвестен, можно сначала посчитать подходящие элементы, затем создать и заполнить массив. Другой вариант — выделить массив с запасом и отдельно учитывать занятые ячейки.

**2. Список `List<T>`**

**`List<T>`** — коллекция на основе автоматически расширяемого внутреннего массива. `T` — тип элементов.

```csharp
List<string> errorLogs = new List<string>();

foreach (string log in logs)
{
    if (log.Contains("Error"))
    {
        errorLogs.Add(log);
    }
}
```

Заранее считать количество ошибок не требуется.

| Запись | Назначение |
|---|---|
| `Add(value)` | Добавить элемент в конец |
| `Remove(value)` | Удалить первое совпадение по значению |
| `RemoveAt(index)` | Удалить элемент по индексу |
| `list[index]` | Получить или изменить элемент |
| `Count` | Количество элементов в списке |
| `Capacity` | Вместимость внутреннего массива |

**`Count ≤ Capacity`**. Допустимые индексы: `0 ≤ index < Count`. У списка нет свойства `Length`.

Расширение: **создать больший массив → скопировать элементы → заменить ссылку на внутренний массив**. Старый массив, если он больше недоступен, позднее освобождает сборщик мусора.

Сам объект списка сохраняется; меняется его внутренний массив. В текущей реализации .NET вместимость обычно удваивается; частота добавлений не определяет коэффициент роста.

Выбор: фиксированное количество элементов → массив; изменяющееся количество → `List<T>`. `LinkedList<T>` — отдельная коллекция, связный список.

**3. Входные параметры и `out`**

**Метод** задаёт алгоритм; входные параметры позволяют выполнять его для разных данных. Обычные параметры передаются по значению.

Через `return` метод возвращает одно значение. Для нескольких результатов используют `out`, кортеж или пользовательский тип.

**`out`** — выходной параметр, передаваемый по ссылке на переменную вызывающего кода.

- Начальное значение перед вызовом не требуется.
- Метод обязан присвоить значение каждому `out` перед нормальным завершением.
- Читать `out` внутри метода можно после присваивания.
- `out` указывается и в объявлении метода, и при вызове.

Пример из лекции: вернуть чётность числа и количество его цифр.

```csharp
public static bool GetNumInfo(int num, out int digitsCount)
{
    bool isEven = num % 2 == 0;
    digitsCount = 1;

    while (num / 10 != 0)
    {
        num /= 10;
        digitsCount++;
    }

    return isEven;
}
```

```csharp
bool isEven = GetNumInfo(10, out int digitsCount);
```

Результат: `isEven = true`, `digitsCount = 2`. Выходную переменную можно объявить прямо в вызове.

Массив `object[]` тоже может содержать результаты разных типов, но требует приведений типов и допускает ошибки во время выполнения.

**4. Кортежи**

**Кортеж** объединяет несколько значений, в том числе разных типов, в одно значение. Типы элементов известны при компиляции.

```csharp
(bool IsEven, int DigitsCount) info = (true, 2);
Console.WriteLine(info.IsEven);
```

Тип результата метода можно записать как `(bool IsEven, int DigitsCount)`, а вернуть значения — через `return (isEven, digitsCount);`.

Два варианта получения результата (используется один):

```csharp
(bool IsEven, int DigitsCount) info = GetNumInfoTuple(10);
(bool isEven, int digitsCount) = GetNumInfoTuple(10);
```

В первой строке создаётся одна переменная кортежа, во второй — две отдельные переменные. Второй вариант называется **деконструкцией**.

Без имён доступны `Item1`, `Item2` и т. д.

- `Tuple<bool, int>` — ссылочный тип.
- Современная запись `(bool, int)` основана на `ValueTuple` — значимом типе.
- Для большого набора характеристик удобнее отдельный тип с понятным именем.

**5. Пользовательские типы**

**Тип** описывает состав данных и доступные действия. **Экземпляр** — конкретные данные этого типа.

```csharp
struct Fraction
{
    public int Integer;
    public int Numerator;
    public int Denominator;
}

class Car
{
    public int Year;
    public string Color;
    public string Model;
}
```

`Fraction` хранит целую часть, числитель и знаменатель; `Car` — год, цвет и модель. Переменные внутри типа называются **полями**. `public` разрешает обращаться к ним извне.

Структуры и классы могут содержать поля и методы.

```csharp
Car car = new Car();
car.Year = 2023;
car.Color = "Red";
car.Model = "Toyota Corolla";

Fraction fraction = new Fraction { Integer = 1, Numerator = 1, Denominator = 2 };
```

Последняя строка использует **инициализатор объекта**: присваивания разделяются запятыми, точка с запятой стоит после всей конструкции. При известном типе допустима сокращённая запись `new()`.

Возврат нескольких связанных значений через структуру:

```csharp
public static Fraction Divide(int num1, int num2)
{
    return new Fraction
    {
        Integer = num1 / num2,
        Numerator = num1 % num2,
        Denominator = num2
    };
}
```

Для этого примера: `num1 ≥ 0`, `num2 > 0`. `Divide(7, 3)` → `2 1/3`. Это смешанная дробь. Хранение числителя и знаменателя позволяет представить рациональное число точно; `float` и `double` многие дроби представляют приближённо.

Также упомянуты `enum`, `interface` и `record`; подробно они будут изучаться отдельно.

**6. Значимые и ссылочные типы**

| Свойство | `struct` | `class` |
|---|---|---|
| Категория | Значимый тип | Ссылочный тип |
| Переменная содержит | Само значение | Ссылку на объект |
| При присваивании | Копируются значения полей | Копируется ссылка |
| Обычная передача в метод | Копия значения | Копия ссылки на тот же объект |

```csharp
public static void Test1(Fraction fraction)
{
    fraction.Integer = 2;
}

public static void Test2(Car car)
{
    car.Year = 2026;
}
```

Если исходная дробь имеет `Integer = 1`, а машина — `Year = 2023`, то после вызовов:

```csharp
Test1(fraction);
Test2(car);

Console.WriteLine(fraction.Integer); // 1
Console.WriteLine(car.Year);         // 2026
```

- `Test1` изменяет локальную копию дроби → исходное значение сохраняется.
- `Test2` получает копию ссылки на общую машину → изменяет исходный объект.

Имена параметров могут совпадать с именами переменных вызывающего метода: это разные переменные. Присваивание параметру новой машины изменило бы только локальную копию ссылки.

**Копирование структуры не означает глубокое копирование**: если поле содержит ссылку, копируется ссылка на тот же объект.

**Выбор типа:** независимые значения, например дроби и координаты → `struct`; объект с общим изменяемым состоянием, например машина → `class`.

Место хранения зависит от контекста: структура может находиться внутри объекта или массива в куче. Наличие `new` само по себе не определяет категорию типа.
